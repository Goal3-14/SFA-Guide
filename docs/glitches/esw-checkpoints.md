# ESW Checkpoints

An **ESW (Event Storage Warp) checkpoint** is a checkpoint which stays active even after quitting to the main menu and opening another file. This is the mechanic underlying all ESW-family skips.

## Rules

- All files used during runs must be **created during runs**, except for **NG+** where pre-made files at ESW checkpoints may be used.
- All ESW variants require either **dying or voiding out** to trigger the checkpoint.
- The exact save slots used have no effect.

## Variants

The mechanic supports five types of warp; only the first two are currently used in runs:

- **File Copy Warp (RESW)** &mdash; copies a file at any ESW checkpoint to another file. See [RESW](../skips/resw.md).
- **Event Storage Warp (ESW)** &mdash; warp from any file to the position of another file at an ESW checkpoint. See [ESW](../skips/esw.md).
- **Slingshot Warp** &mdash; warp from an ESW checkpoint to the position of any other save file (aka RRESW).
- **Same-File Warp** &mdash; copy Fox's inventory (low-flags) from "back in time" at any ESW checkpoint.
- **Deathless ESW** &mdash; perform an ESW without dying on the 2nd file; instead die on the ESW checkpoint file.

## Used by

ESWs are used to travel faster and to escape softlocks, enabling more skips &mdash; mainly [K3E](../skips/k3e.md) and [K4E](../skips/k4e.md).

There are **23 ESW checkpoints**, but only 5 are currently used in runs:

- 2 at the start of Dark Ice Mines
- 1 at the start of Cloudrunner Fortress
- 1 in Thorntail Hollow (only useable immediately before and after collecting Portal Device)
- 1 at the end of the K5 Shrine

The DIM ESW is the earliest one that can be reached from a new file.
