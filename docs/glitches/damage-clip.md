# Damage Clip

A v1.0-only glitch: in this version Fox has collision with explosive barrels. By having the cannon hit you while holding a barrel, you drop the barrel onto yourself &mdash; the push clips you out of bounds.

**v1.0 only.** This is the reason [Any%](../categories/any-percent.md) is run on v1.0 exclusively &mdash; v1.1 removed the collision.
