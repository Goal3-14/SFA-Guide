# Running vs Rolling

## As Fox

Just running is faster than rolling, *unless* you roll frame-perfectly on every roll. The beginning of Fox's roll is faster than his running speed, but the end of the roll is slower &mdash; so **rolling into cutscenes** can be slightly faster.

## As Krystal

Rolling may be technically faster when going in perfectly straight lines, but not enough to matter in practice.

## Roll Cancel (TAS only)

There is a TAS-only technique called **Roll Cancelling** where you can pull out Fox's shield for one frame to cancel the slower part of the roll, then immediately on the next frame roll again to keep going at the faster speed.

This is too precise to be RTA-consistent &mdash; doing it badly will lose time over just running.

### Frame timing

- Press **X** to roll
- On frame 14, press **R** to shield
- On frame 15, release shield and press **X** to roll
- Repeat
