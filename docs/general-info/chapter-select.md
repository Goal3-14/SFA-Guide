# Chapter Select

A code that lets you jump to immediately after collecting each spellstone and returning to Thorntail. Useful for practice. Chapter select will **override the selected file**.

## Input

1. Open a file so that the options are *Play Game* and *Erase Game*.
2. Hold **Z** the whole time.
3. Press **D-pad Down, Up, Y, Y, R**.
4. You will hear a sound effect when done correctly.
5. Press *Start Game*.

## Slots

1. Start of game (Galleon)
2. After DIM
3. After CRF
4. After WC
5. After DR
