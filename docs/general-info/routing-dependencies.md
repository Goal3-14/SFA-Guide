# Routing Dependency Overview

The end sequence of the game is triggered by collecting K5 from WC2. The portal to K5 can be accessed at any point after reaching WC, but the portal won't work unless you've returned SS4 to OFP2, and OFP2 cannot be entered without first returning SS2 to OFP1. To reach the end of K5, Ice Blast is required. You cannot fly to a dungeon without having unlocked all dungeons before it, so all dungeon gateways need to be unlocked to reach WC and DR.

The point of the route is to:

- Open all gateways to dungeons
- Collect and return SS2 and SS4
- Collect Ice Blast
- (DR additionally requires flame command from DIM to complete.)

## Ice Blast / Unlock DIM

There is no known way to enter VFP early using glitches, and you cannot access VFP2 with SS3 before having entered VFP1, so collecting the first spellstone from DIM is required. You do not need to finish VFP1 and can leave as soon as you collect Ice Blast. DIM is also required to unlock flame command.

To unlock DIM you need to reach Garunde Te, which is a requirement anyway as all gateways are required. Garunde Te can be accessed via [DIME](../skips/dime.md), [Shield Hover](../skips/shield-hover.md), or by getting all white grubtubs from the TTH well.

## SS2 / Unlock CRF

Unlocking SS2 normally requires you to collect K2 to get a wallet, so you can afford the 60 scarabs to enter Cape Claw. This can be skipped using [GBS](../skips/gbs.md) for CC1 and [CCE](../skips/cce.md) for future visits. Save the Queen and complete Cloudrunner Fortress as normal.

## Unlock WC

To unlock Walled City you need the portal device from completing the egg minigame, which is triggered by returning K3 from LFV to KP. Returning this spirit requires disguise, which is collected from CRF anyway.

- In **Single File** routes K3 can be collected by finishing OFP1 then doing LFV as normal.
- In **ESW** routes you can do [K3E](../skips/k3e.md) to collect the spirit without doing LFV. This typically allows us to delay OFP1 until the end of the run so we can do OFP1 and 2 at the same time to skip having to make multiple trips.

## Unlock DR

Unlocking DR is triggered by returning K4 to KP. Collecting K4 is the biggest difference between Single File and ESW routes.

- In **Single File** routes you are required to actually complete WC, get SS3, and return it to VFP (this doesn't require you to have finished VFP1 as long as you have at least collected Ice Blast before collecting SS3). This allows you to get a wallet and buy the snowhorn artifact to do the SHW trial and unlock K4 normally.
- In **ESW** routes all this can be skipped by doing [K4E](../skips/k4e.md), allowing us to skip SS3 and VFP2.

Returning K4 to KP requires portal device, which you get anyway.

## Entering OFP

If you skip CC2 by doing OFP1 at the end of the run with OFP2, then the water will not be lowered and the fire gem door will be closed. OFP can be accessed using [CC3 Airswim](../skips/cc3-airswim.md). This needs portal device and Ice Blast, which you get anyway. There are alternate ways which do not need Ice Blast, but they are slower.
