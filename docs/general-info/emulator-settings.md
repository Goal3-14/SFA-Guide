# Emulator Settings

If Dolphin is crashing, work through these in order.

## First pass

- **Settings &rarr; General &rarr;** turn off *Enable Dual Core*
- **Settings &rarr; Advanced &rarr;** turn off *Enable MMU*

## If still crashing

- **Settings &rarr; General &rarr;** turn off *Enable Emulated CPU Clock Override*
- **Settings &rarr; General &rarr;** turn off *Enable Emulated Memory Size Override*

## Practice tooling

If you can run the game well on emulator, it's highly recommended for learning &mdash; the [Any% practice tool](../tools/any-practice-tool.md) and [memory heap visualisers](../tools/any-heap-visualiser.md) make K5E and SRM setups much faster to drill than on console.
