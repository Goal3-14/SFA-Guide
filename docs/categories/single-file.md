# Single File

Single File acts as a more restricted category &mdash; only one file allowed, **void travel and shield hover banned**. Requires collecting every spellstone, with most major glitches and tricks allowed. The only major collectable skipped is K2.

Despite being more restricted, this results in many big tricks and glitches **unique to this route**, making it the most difficult full-game category to learn the WR route for &mdash; though many of the big tricks are optional WR-only strats.

**Optimal route ~4 hours.**

## Route options

The main routing options depend on whether you do two specific tricks &mdash; both using [Ball Entanglement](../glitches/ball-entanglement.md): [FGL](../skips/fgl.md) and [Ball Hover](../skips/ball-hover.md).

FGL is not bad, but Ball Hover is **WR-only** &mdash; it requires extremely precise positioning, angles, and a frame-perfect input while being 3 hours into the run, losing several minutes on each failure. Both require pressing A one frame after Y (frame-perfect but doable, similar to Cam Lock).

### FGL

FGL lets you collect the fire gem without needing to use the gold bar ladder to reach the disguise entrance. This allows you to do [Gold Bar Skip](../skips/gbs.md) instead of [CCE](../skips/cce.md) for WC1, saving time, and FGL itself is also faster than the intended fire gem route. <!-- TODO: confirm total time save (original guide had blanks) -->

Overall **FGL + GBS saves ~1:30&ndash;2:00** over collecting the fire gem normally and doing CCE.

### Ball Hover

Ball Hover lets us complete the SHW trial and access K4 without needing to get the key from the Queen Earthwalker by collecting the white grubtubs. **Saves ~3 minutes** by skipping the well and the Queen cutscene. **WR-only strat.**

### DIM

To enter K4 you need to collect the Snow Horn from DIM, which makes the time save from Bike Skip less than it would normally be in multi-file categories. However, getting the Mammoth for Bike Skip also enables [Cog Skip](../skips/cog-skip.md), which lets you collect the Snow Horn without the 3 cogs and cannon.

Cog Skip saves around **1 minute**, so overall **Bike Skip + Cog Skip** saves a significant amount &mdash; but Bike Skip is very difficult and long, losing 7&ndash;8 minutes if you fail it at the end. The alternative is [Gate Despawn](../skips/gate-despawn.md) + [Seam Walk](../skips/seam-walk.md).

Cog Skip is **not worth it without Bike Skip** &mdash; you can skip unlocking the Mammoth using Gate Despawn, then play normally to collect the Snow Horn. Bike Skip is still worth the time save even without Cog Skip.

## Game versions

All glitches and tricks for this category can be used on **any version** of the game. JP text saves 4&ndash;5 seconds. v1.1 saves 15 seconds over v1.0. See [Versions](../general-info/versions.md).
