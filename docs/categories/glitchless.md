# Glitchless

Glitchless requires you to complete every section in the game in the developer-intended order **without the use of glitches**. However the category does still have certain tricks that are considered glitchless &mdash; notably [Seam Walk](../skips/seam-walk.md) and [Electric Slide](../skips/electric-slide.md).

The optimal route is around **5 hours**. There are no routing differences or options.

## Allowed but unusual

These look glitchy but **are allowed**:

- [Seam Walk](../skips/seam-walk.md)
- [Electric Slide](../skips/electric-slide.md)
- [Neutral rolls / ladder skips](../tech/neutral-rolls.md)

## Banned techniques

Anything that uses a glitch is banned, including:

- All [Glitches](../glitches/index.md) pages.
- All [Skips](../skips/index.md) that rely on a glitch &mdash; the page is tagged with categories it's allowed in, so any skip *not* tagged `glitchless` is banned.

## Game versions

All versions allowed. JP text saves 4&ndash;5 seconds. v1.1 saves 15 seconds over v1.0. See [Versions](../general-info/versions.md).
