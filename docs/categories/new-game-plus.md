# New Game+

New Game+ allows you to start the run with **premade files** already created and at [ESW](../glitches/esw-checkpoints.md) checkpoints. The run only allows for the use of basic [ESWs](../skips/esw.md) in order to get a new file to the end of the game by warping to the positions of the other files.

The route for this category is around **32 minutes**.
