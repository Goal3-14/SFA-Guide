# Categories

Each category page is a **narrative route guide** &mdash; it walks you through the run in order, linking out to the per-area [Locations](../locations/index.md) pages for detail.

- [Any%](any-percent.md) &mdash; reach the credits as fast as possible.
- [100%](hundred-percent.md) &mdash; full completion (definition TBD).
- [Glitchless](glitchless.md) &mdash; no out-of-bounds, no major skips.

!!! info "Category definitions"
    The exact rules &mdash; what counts as 100%, which glitches are banned in glitchless, etc. &mdash; are defined by the [speedrun.com leaderboard rules](https://www.speedrun.com/sfa) and mirrored at the top of each category page below. If the leaderboard rules and this site disagree, the leaderboard wins; please open a [correction issue](https://github.com/Goal3-14/SFA-Guide/issues/new?template=correction.yml).
