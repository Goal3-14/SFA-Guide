# Spellstones

The Spellstone categories only require you to collect a specific spellstone &mdash; each category's time ends after collecting it. All Spellstones can be collected as your first spellstone using glitches; for SS3 and SS4, multiple files are needed.

## Sub-categories

- **SS1** &mdash; Volcano Force Point Temple ice blast.
- **SS2** &mdash; Cloudrunner Fortress. **Highly recommended beginner category.**
- **SS3** &mdash; Walled City.
- **SS4** &mdash; Ocean Force Point Temple.

There are also **Spellstones SRM** and **Spellstones NG+** variants. <!-- TODO: these were placeholders in the source guide. Document as routing solidifies. -->

## Why SS2 is the recommended starting category

It's only around **1.5 hours** so much shorter than full-game categories, but it still contains the games **two most important tricks** ([Air Swim](../glitches/air-swim.md) and the [CCE](../skips/cce.md) family) that all other categories use. Learning SS2 builds the foundation for everything else.
