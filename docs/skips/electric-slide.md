# Electric Slide

**Location:** Ocean Force Point Courtyard &nbsp;&middot;&nbsp; **Considered glitchless &mdash; allowed in all categories.**

## What it does

When entering the OFP courtyard, you can **zoom and unzoom to reload the Electric Tile Puzzle**. This sets the puzzle solution to **1, 2, 3** &mdash; then the remaining tiles don't matter.

Works for **both Ocean 1 and Ocean 2**. The state stays active as long as you don't reset the console or open another file &mdash; so doing the trick for Ocean 1 makes the Ocean 2 tile puzzle 1, 2, 3 as well.

## Setup

While entering the courtyard, **zoom and unzoom while in the red box**.
