# K4E (Krazoa 4 Early)

**Location:** K4 Shrine &nbsp;&middot;&nbsp; **Glitch used:** [Air Swim](../glitches/air-swim.md)

Collects Krazoa 4 without needing to complete WC1, get SS3, or do VFP2. The biggest single difference between [Single File](../categories/single-file.md) and [Any% No K5E](../categories/any-percent-no-k5e.md) routes.

In ESW routes, this enables skipping the entire SS3+VFP2 chain that Single File requires.

## Video

<https://www.youtube.com/watch?v=BRprk9HpJhQ>

## Escape

The K4 Shrine softlocks after collecting K4 &mdash; escape is via [ESW](esw.md). See [ESW](esw.md) for the example procedure for getting Tricky to flame you to die for the warp.
