# OFP Cam Lock

**Location:** OFP exit &nbsp;&middot;&nbsp; **Glitch used:** [Camera Lock](../glitches/camera-lock.md)

In certain routes you never open the fire gem door to OFPT, meaning you cannot simply leave OFP normally. This cam lock causes the fire gem door to **deload**, allowing you to leave. It also deloads the sharpclaw door, so you can leave even when the water is still raised.

## Setup

Run forward up until you're **more forward than the corner**, then run back around **2/3 the way of the straight** before feeding Tricky. You can press target as soon as Fox is around the corner.

## Reusing the cam lock

This cam lock can be **kept all the way to TTH** to also use for [Queen Cam Lock](qe-cam-lock.md), saving a setup.
