# ESW (Event Storage Warp)

**Glitch used:** [ESW Checkpoints](../glitches/esw-checkpoints.md)

An ESW allows you to **warp to the location of a second file** which is at an ESW checkpoint. This warp also transfers certain game flags &mdash; in practice this only means that an ESW should not be performed after Ocean Force Point 1 has been finished to a file where it has not been completed, as this will undo the progress.

## Procedure

To warp file 1 to the ESW location on file 2:

1. **Save quit file 1.**
2. Start file 2 and hit the ESW checkpoint.
3. **Quit file 2 without saving.**
4. Start file 1.
5a. **If voiding out:** without hitting any checkpoints, save then void out.
5b. **If dying:** without hitting any checkpoints, die then save and continue.

## Variant-specific procedures

Many different ESWs are used throughout the categories, and some locations have specific quirks when ESWing from or to them. The exact procedure is covered in each category's route information.

## Example: K4 escape

The example procedure on the source guide is used to **escape the [K4E](k4e.md) softlock** by warping from the K4 Shrine Entrance to the Thorntail Hollow ESW. The death requires you to get Tricky to use flame on you.
