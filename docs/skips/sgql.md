# SGQL (Super Ground Quake Late)

**Location:** Walled City 2 &nbsp;&middot;&nbsp; **Glitch used:** [Waterfall Jump](../glitches/waterfall-jump.md) &nbsp;&middot;&nbsp; **Used in:** [100%](../categories/hundred-percent.md) only

In 100% it is a requirement to get Super Ground Quake, however there is no good time to get it in WC1 &mdash; so we get it in WC2 instead.

## Setup

1. Do [Waterfall Jump](../glitches/waterfall-jump.md) to get OOB.
2. Use it to **skip needing the King Earthwalker to raise the bridge**.
3. Get Super Ground Quake as normal.
4. **Save quit as soon as you get it** to return to the arwing for [ZGSS](zgss.md).
