# WC Escape

**Location:** Walled City &nbsp;&middot;&nbsp; **Used in:** Any% Normal Route only

After [K5E](k5e.md) the game is in a glitched state and you don't have Tricky. WC Escape is the sequence to **escape Walled City** to complete the run.

## When it's needed

Required for the [Any% Normal Route](../categories/any-percent.md). The 2-File Route skips WC Escape entirely &mdash; this is the main reason 2-File is significantly easier to learn.

## Risk

Has to be done **back-to-back after [K5E](k5e.md)**, and **failing it requires redoing the whole of K5E**. WC Escape is also relatively difficult, so this is the primary risk in a Normal Route attempt.
