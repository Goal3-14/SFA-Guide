# Tools

External programs and resources that runners use.

## Visualisation and reference

- [3D Map View](3d-map-view.md) &mdash; view a 3D model of every map in the game.
- [Trigger Viewer](trigger-viewer.md) by RenaKunisaki &mdash; visualise triggers, curves, and objects per act.

## Practice

- [Any% / K5E practice tool](any-practice-tool.md) by Goal3.14 &mdash; drill the memory manip without re-running every time.
- [Shield Hover Setup Finder](shield-hover-setup-finder.md) by Goal3.14 &mdash; emulator-driven starting-position finder.

## Memory / Heap

- [Any% Heap Visualiser](any-heap-visualiser.md) by Zcanann &mdash; live memory values while practicing K5E.
- [Heap Mapper](heap-mapper.md) by Goal3.14 &mdash; track the memory heap hash values to help finding consistent SRM setups.
