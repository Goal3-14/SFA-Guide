# Trigger Viewer

**By:** RenaKunisaki &nbsp;&middot;&nbsp; **Use case:** visualise triggers, curves, and objects in each act &mdash; useful for understanding why a skip works.

**Repository:** <https://github.com/RenaKunisaki/SFA-Browser>

## Install

1. Click the green **Code** button to download the zip.
2. Unzip it.
3. Double-click on the file called **server**.
4. Go to <http://localhost:8000/>.
5. Where it says **ISO File**, click **Load File** and select an ISO of the game. It works best with a **US 1.0 ISO**.

## Using the map viewer

On the map viewer under **objects** you have to select an act to get the stuff to load, and turn on triggers (and maybe curves).

What you need to click to get the triggers to show seems kinda buggy when changing maps &mdash; **just click options till it works**.
