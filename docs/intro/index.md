# Intro

Star Fox Adventures (GameCube, 2002) is the canonical speedrun target on this site. The game is normally a 20+ hour action-adventure; current runs beat the credits in **under an hour** by chaining out-of-bounds tricks, ESW save-file warps, and a precise memory manipulation.

Watch the intro video for the run at a glance:

<https://www.youtube.com/watch?v=hFpPpw8YgOE>

## About this guide

This is the **canonical source of truth** for SFA speedrun information. It supersedes the [speedrun.com guides](https://www.speedrun.com/sfa/guides), which mirror it.

How to read it:

- Brand new? Start with **[General Info](../general-info/index.md)**, then pick a **[Category](../categories/index.md)**.
- Looking up a specific glitch or skip? Jump to **[Glitches](../glitches/index.md)** or **[Skips](../skips/index.md)**.
- Press <kbd>/</kbd> anywhere to search.
