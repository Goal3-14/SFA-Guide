## About this guide

This is the **community-maintained** speedrun reference for SFA. It is the canonical home for routes, tech, glitches, and tricks. The [speedrun.com guides](https://www.speedrun.com/sfa/guides) link back here for the current version of everything.

How to read it:

- If you are brand new, start with **[General Info](../general-info/index.md)**, then pick a **[Category](../categories/index.md)**.
- If you are looking up a specific glitch or skip, jump straight to **[Glitches](../glitches/index.md)** or **[Skips](../skips/index.md)**.
- If you want to know what is in a specific area, browse **[Locations](../locations/index.md)**.
- Press <kbd>/</kbd> any time to search.
